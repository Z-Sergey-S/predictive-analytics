# Лабораторная работа №2 - Виртуальный датчик для контроля процесса обжига в печи

### Выполнил: Жеребцов Сергей
### Группа: М8О-203СВ-25

## Исходные данные

- `data_train.csv` - минутные измерения 16 показателей телеметрии за 8 месяцев для обучения;
- `target_train.csv` - лабораторные замеры концентрации продукта, нерегулярные и с задержкой 10-15 минут;
- `data_test_small.csv`, `target_test_small.csv` - аналогичные данные для тестирования.

CSV-файлы не включены в репозиторий. Перед запуском нужно скопировать четыре файла из задания в папку `lab_2`, рядом с `lab2.ipynb`.

## Запуск

Нужны Python 3.12 и VS Code с расширениями Python и Jupyter.

В терминале VS Code из корня репозитория выполнить:

```bash
cd lab_2
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

Открыть `lab2.ipynb`, через Select Kernel выбрать Python из `.venv` и нажать Run All.

## Что было сделано

Были проверены повторы и пропуски, построены графики телеметрии и лабораторных проб. По текущим и прошлым показаниям было подготовлено 208 признаков. Время target было принято за момент отбора пробы, а лабораторный ответ считался доступным через 15 минут. Это допущение, поскольку смысл временной метки отдельно не указан.

Были обучены Ridge, случайный лес и градиентный бустинг. Модель была выбрана на более поздней части обучающих данных, после чего проверена на отдельном test. Для сравнения были взяты среднее обучающей части и последняя доступная проба. Дополнительно были проверены остатки, важность признаков и время работы; для AIC/BIC были построены две OLS-регрессии.

## Выводы

По validation был выбран HistGradientBoosting. На 318 тестовых пробах его RMSE составила 0.0774, MAE - 0.0626, WAPE - 29.86%, а совпадение направления изменений - 51.43%. На test наименьшая RMSE среди трёх моделей получилась у случайного леса: 0.0745. У последней доступной пробы MAE оказалась ниже, чем у бустинга: 0.0595.

Прогноз сглаживает высокие пики, а ошибки остаются связанными во времени. Качество было проверено только в моменты лабораторных проб, поэтому точность между ними неизвестна. Назначение каналов телеметрии не указано, что ограничивает объяснение физических причин результата.
